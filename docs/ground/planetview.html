→ How the ground becomes the fight — what's real

You don't pick a battle's environment from a menu — the location picks it for you, and the AI reads the same thing off the same hex. But be exact about what "environment" means to the engine today, because it is narrower than it looks. The ground resolver reads two things; the space resolver reads nothing about location at all.

LayerWhat the ground resolver does with itGrade
Terrain (per hex)Cover multiplier on the defender + unit-type affinity (armour/artillery) + march-cost. Real numbers from GroundTerrain.cs.LIVE
Condition → surface hazardsAn attrition — a per-hour health bleed on units standing in it (vacuum, toxic air, fire, cryo, corrosive). A sealed unit is exempt from vacuum/toxic. Real magnitudes from PlanetEnvironmentFactory.cs.LIVE
Condition → gravity / temperature / radiation / day-lengthNothing. The values exist on the body but no combat code reads them (temperature only matters by deciding which hazard was generated).DATA
Storm hazards (dust / ash / lightning = SensorJam)Nothing yet. The generator makes them, but the resolver's attrition step skips SensorJam (it isn't a damage effect); ground detection doesn't read it either.DATA
Gravity → movement · weather → sight · condition multipliersThe richer "environment reshapes the whole fight" model (closing speed, detection range, damage-by-nature). Proposed in the design docs; not wired.THEORY
The space auto-resolverNothing. AutoResolve / CombatEngagement read no terrain, no hazard, no planet — space combat is environment-blind.DATA
So "wired to the auto-resolver" means the GROUND resolver, and it means two live wires: the terrain triangle and the surface-attrition bleed. Everything else this view shows is either data the game holds but combat ignores, or a design proposal. That honesty is the point of the grades — the panel to the right never blurs the three.

⚑ The real gap this surfaces

Grounding the view in real data turned up a genuine cradle-to-grave hole, worth the developer's eye.

The only surface-hazard armour the game can build is the sealed suit — and it only stops vacuum and toxic air. The sealed-systems component (the one buildable seal) folds into a unit's EnvironmentalResistance for Vacuum and ToxicAtmosphere only. There is no base-mod component that resists fire, cryo, or corrosive attrition — so on Venus, a fully sealed marine still burns from the fire tornadoes (≈23/hr) and the corrosive superstorm (25/hr); sealing only saves them the 3/hr toxic bleed. The engine supports heat/corrosion resistance (the EnvironmentalResistance map is keyed by every hazard kind) — but the component that writes it was never built. A real "you can't hold this world without the right kit" decision is one component away.
