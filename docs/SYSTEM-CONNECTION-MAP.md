# Pulsar4X — System Connection Map (the "map the connections first" tool)

**What this is — read this before touching any system.** This is the wiring diagram of the whole
game in table form: for every system, it lists the other systems it's plugged into — what feeds *into*
it, what it feeds, what it shares state with, and what it triggers. It is the **Prime Directive** ("map
the connections first") made into a lookup table. You do not work a system alone: find its row, read
what it connects to, then go read *those* rows too. A change to one station ripples down the line.

**This is the ONE owner of system-to-system connections.** Nothing else in the docs holds the connection
graph — this file is where it lives.

**What this file deliberately does NOT carry** (so it can never rot from stale status marks):
- **Build status** (is it done / partial / dark / absent) lives in **`docs/DOCS-INDEX.md`**.
- **Test & gauge status** (is there a test watching it, and is it green) lives in **`docs/TESTING-TRACKER.md`**.

Keep those two columns out of this file. Here we track connections and nothing else.

*Extracted from `docs/archive/SYSTEMS-STATUS-AND-TEST-PLAN.md` on 2026-07-13 — this file lifts out only that doc's
"Connected to" column. If you find a connection this map doesn't list, add it in the same commit as the
change that revealed it.*

> **A CUT WIRE IS ALSO A CONNECTION.** Since 2026-07-27 this file also carries **⚡ BROKEN AND MISSING EDGES**
> (bottom section): pairs of systems the design requires to be plugged together where the wire is missing,
> one-way, or reads a value that is always zero. A diagram that draws only the wires that exist reads as "the
> rest is fine." **Read that section too — several of its rows are live bugs, not future work.**

## ⚡ BROKEN AND MISSING EDGES — wires that SHOULD be connected and are not (added 2026-07-27, OPERATION GROUND TRUTH)

**Why this belongs in the connection map, and why it is not a status column by the back door.** This file bans
build/test status marks so it cannot rot. A **cut wire is not a status — it is a connection fact**: these are pairs
of systems the design requires to be plugged together, where the wire is missing, one-way, or reads a value that is
always zero. A wiring diagram that draws only the wires that exist will get someone hurt, because the reader
concludes the rest is fine. Each row names the two ends and the exact line where the wire should be.

*Evidence for every row: `docs/DOCS-AUDIT-2026-07-27.md`. Fixes are scheduled as slices in
`docs/ground/PLANETARY-FUNCTIONAL-PLAN-2026-07-27.md` — the slice key is in the last column.*
